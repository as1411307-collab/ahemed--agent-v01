# المنظومة — Private Agent Core

هذا المستودع يحتفظ الآن بالنواة **TypeScript / Fastify / SQLite** والعقود والاختبارات المشتركة فقط.

**تم استبعاد تطبيق Expo / React Native التجريبي.** واجهة iPhone الأصلية بـSwiftUI هدف لاحق، **وليست موجودة أو مختبرة في هذا الفرع**. لا تُعرض موافقة DEMO على أنها تنفيذ حقيقي.

## تشغيل النواة في بيئة تطوير

```sh
npm ci
cp apps/core/.env.example apps/core/.env
# ضع قيم بيئة التطوير محليًا فقط، ولا ترفع أسرارًا إلى Git.
npm run verify
npm run readiness:dev
npm run core
```

- يعتمد مسار النموذج الحالي على **Anthropic API**؛ لا تفترض أن اشتراك المحادثة يشمل واجهة API.
- تتحقق `npm run verify` من اختبارات Core وفحص أنواع Core والعقود.
- `npm run readiness:prod` يفشل حاليًا عن قصد، لأن التحقق من صلاحيات n8n والمسارات الحساسة لم يُثبت.
- يرفض `apps/core/src/main.ts` تشغيل الإنتاج إذا لم تستوفَ بوابة الأمان؛ لا تتجاوزها.
- مسارات الموافقة الموقَّعة الحالية **DEMO / NO EFFECT**، ولا تثبت تشغيل أداة خارجية أو اعتماد iPhone حقيقي.
- استخدم النواة محليًا فقط لحين إثبات الاتصال الآمن؛ لا تنشر منفذ التطوير على الإنترنت.

## الملفات المهمة

- `packages/contract/src/index.ts`: العقود الحالية.
- `apps/core/src/`: النواة وأدوات الملفات وقيود الأمان.
- `apps/core/test/`: اختبارات الحالة والأمان والتوقيع.
- `apps/core/test/support/approval-display.ts`: منطق تنسيق التوقيع القديم محفوظ **كمرجع للاختبارات فقط**، وليس عميل iPhone.
- `docs/STATUS.md`: الحالة المعروفة والقيود.
- `docs/SECURITY_GATES_PHASE1.md`: الحدود التي تمنع إعلان الجاهزية.

هذه عملية إزالة للعميل التجريبي، لا إعادة بناء أو إثبات Production Readiness.
