# Architect Control — واجهة داعمة للعالم

`apps/studio` تطبيق React + TypeScript + React Flow، وليس تنفيذ Unreal أو بديلًا للعالم السينمائي. لا يعرض نشاط وكلاء مصطنعًا أو فيديو مشهد باعتباره تشغيلًا. يبقى SKY SANCTUARY غير متاح حتى اختيار الأصل الجاهز واعتماد شرائه وتشغيله بأدلة فعلية.

## التشغيل

من جذر المستودع، بعد تثبيت اعتماديات npm workspaces:

```text
npm run start -w @nexus/studio
```

العنوان المحلي `http://127.0.0.1:5173`. يمرر Vite طلبات `/nexus` إلى Gateway المحلي عند `127.0.0.1:8788`. لا يضيف CORS عام ولا ينشر خدمة. البناء: `npm run build -w @nexus/studio`؛ فحص الأنواع: `npm run typecheck -w @nexus/studio`.

أدخل **رمز وصول Gateway** في حقل الاتصال، وليس مفتاح Anthropic أو أي مزود. يبقى الرمز في ذاكرة تبويب المتصفح فقط، ويُحذف عند إعادة التحميل أو قطع الاتصال. لا يوضع في التخزين المحلي أو رابط URL أو متغير frontend. يستخدم الطلب `Authorization: Bearer` إلى Gateway؛ لا تتصل الواجهة بمزود النموذج أو Hermes مباشرة.

## الوظائف وحدود الأدلة

- Mission Theater يعرض المهمات وحالتها والأحداث التي يعيدها Gateway فقط. طلب STOP ليس دليل توقف؛ تبقى الحالة المرصودة هي المرجع. تمر أوامر steer والموافقات بالخادم وتُرفض عند عدم الدعم أو انتهاء الصلاحية.
- Architect يعرض الأدوار المعرّفة في React Flow دون اختلاق حواف تفويض أو عرضها كوكلاء يعملون. سحب عقدة يعدّل ترتيب المعاينة المحلي فقط، ولا يغير مسار تنفيذ. تعديل الإعدادات الفعلي عبر JSON، ثم معاينة محلية، ثم تحقق خادمي، ثم Apply مع رقم مراجعة لمنع سحق تعديل متزامن.
- Undo/Redo لمسودة محلية؛ Restore يطلب إنشاء إصدار جديد من نسخة محفوظة ولا يعكس آثار الأدوات الخارجية. حفظ الإعدادات المطلوبة لا يثبت تطبيقها في Unreal أو خدمة الوكيل.
- Integration Hub يعرض الحالة والسبب من الخادم؛ زر Test يختبر الاتصال ولا يمنح صلاحية. غياب الاعتماد أو التكامل يظهر كـunavailable/blocked وفق استجابة الخادم.
- Replay قراءة فقط مع seek على الأحداث المسجلة. لا يعيد إرسال أداة أو قرار موافقة، ولا يخترع أحداثًا مفقودة. الأوامر الحية غير معروضة في صفحة Replay.
- لا صوت Listening/Speaking ولا صور Unreal مزعومة. المعاينة البصرية بطاقة ثابتة موسومة PREVIEW. تلتزم الواجهة بتقليل الحركة والتباين وحالات نصية لا تعتمد على اللون وحده.

هذه صفحة توثيق للسلوك المنفذ في الواجهة. الاختبار الحي للمحرك والتكاملات أو العالم يحتاج خدمات واعتمادات وأصلًا وعتادًا متاحًا؛ نجاح بناء الواجهة لا يثبتها.

## دليل متصفح فعلي — 21 أكتوبر 2026

نجح `npm run test:browser -w @nexus/studio` على Chromium النظامي: مصادقة صحيحة وخاطئة، عدم حفظ الرمز في storage/URL، مسودة لا تغيّر الخادم، Validate/Apply، Undo/Redo، Restore، تعارض409، مهمة محجوبة دون run أو tool مصطنع، Replay دون أوامر تنفيذ، وحالات تكامل غير متصلة. الاختبار يستخدم Gateway الحقيقي وقاعدة مؤقتة، دون Hermes أو اعتماد مزود. داخل sandbox قد يحتاج سماح الشبكة المحلية؛ خارجها يحتاج متصفح Playwright أو `BROWSER_BIN` صالحًا.
