GetLayers: الطريقة + مشاهد مكتوبة عليها

برومبتات GetLayers نفسها مدفوعة. اللي يفيد منهم هو الهيكل: البرومبت يحمل "نية" الهندسة والإضاءة والكاميرا والمواد بالقيم اللي ضبطتها، وبعدين تعدّل عنصر واحد كل مرة. المشاهد الثلاثة تحت مكتوبة على نفس الهيكل لتطبيقك.

طريقة GetLayers (كما هي في موقعهم)

Method
How GetLayers prompts work (from getlayers.ai):
1. Launch the live preview: the real three.js scene runs sandboxed; everything past this point responds to you, not a video.
2. Dial in the look: swatches recolour, sliders move the parameters that matter, randomize finds the accident you wouldn't have typed. Restart re-mounts with your current values when you change something structural (counts, geometry, density).
3. Drop a UI on top (optional): put a real page layout over the scene. "Copy prompt + UI" returns both the scene and the section built over it, in one instruction.
4. Copy the prompt: it carries geometry, lighting, camera and material intent, with the values you dialled in, not the ones it shipped with.
5. Paste it, then iterate one element at a time: geometry, then lighting, then camera, then materials. Describe the behaviour you want in plain words ("the camera drifts closer as you scroll, particles lag behind it"). Scroll and hover motion usually takes several passes; that is normal for a scene.

مشهد 1: أرض ذهبية سلكية تتنفس (اللي في النموذج الحالي)

مكتوب على طريقتهم
Build a three.js scene (r128+, plain JS, no React) as a full-bleed transparent canvas behind a mobile UI.

GEOMETRY
- PlaneGeometry 30×30 with 110×110 segments, rotated flat (rotateX -90°), translated to y=-1.2, z=-3.
- Vertex displacement in the vertex shader: h = sin(x*0.55+t*0.6)*0.22 + sin(z*0.7-t*0.45)*0.22 + sin((x+z)*0.3+t*0.35)*0.35 + sin(x*1.3-z*0.9+t*0.9)*0.07.
- Ripple term from the centre: + sin(d*2.2 - t*3.2) * exp(-d*0.26) * uRipple * 0.9, where d = length(xz).
- Render the same geometry twice: as a wireframe mesh and as points (vertex dots).

LIGHTING / FOG
- No lights. Additive blending, depthWrite off.
- Fog by alpha: vFog = clamp((-viewZ - 4) / 17, 0, 1); line alpha = (1-vFog)*0.5*(0.5+0.5*smoothstep(-0.3,0.7,h)); dot alpha = (1-vFog)*softCircle*(0.55+0.45*smoothstep(-0.3,0.7,h)).

CAMERA
- PerspectiveCamera fov 50, position (0, 2.4, 6.8), lookAt (0, -0.2, -1).
- Pointer parallax: camera.x = px*0.7, camera.y = 2.4 - py*0.35, eased 6% per frame.

MATERIALS
- ShaderMaterial, uColor = app accent (#c9a24a gold; #35d6ff for the HUD theme; #ff7a2f for the ember theme), lerped over ~0.5s when the theme changes.
- Point size (2.8 - vFog*2.0) * devicePixelRatio.

BEHAVIOUR (ties to the agent state)
- idle: speed 1, ripple 0, accent color.
- running: speed 1.7, ripple 1.
- waiting for approval: speed 0.6, ripple 0.25, color = warn (#e8b64f).
- stopped: speed 0.35, ripple 0, color = danger (#ff4d57).
- done: speed 0.9, color = ok (#8fd4a0) for ~2.5s, then back to accent.
- Pause the loop when document.hidden; one static frame under prefers-reduced-motion; fall back to a 2D particle canvas if WebGL is unavailable.

مشهد 2: القلب الحي (حلقة برتقالية + نواة جسيمات)

مكتوب على طريقتهم
Build a three.js "living core" (r128+, plain JS) sized 180×180 CSS px, transparent background, to sit at the centre of a command-deck screen.

GEOMETRY
- Nucleus: Points, 2,400 particles in a Gaussian cloud of radius 0.35; each particle orbits slowly on its own axis (seed-based) and breathes ±8% with sin(t*1.2).
- Ring: TorusGeometry radius 0.75, tube 0.025, 180×16 segments, in the XY plane, with a slow wobble: rotation.x = 0.35 + sin(t*0.4)*0.08.
- Ribbons (active state only): 5 TubeGeometry ribbons along CatmullRom curves that spiral out from the ring to radius 1.6 and fade; regenerate their control points every 3s with an eased crossfade.

LIGHTING
- Additive blending everywhere; no scene lights. A PointLight is not needed; brightness comes from alpha stacking.
- Soft bloom via a second, larger, lower-alpha copy of the nucleus (radius ×1.6, alpha ×0.25).

CAMERA
- PerspectiveCamera fov 35 at (0, 0, 3.2) looking at origin; gentle idle drift of ±2° on Y over 9s.

MATERIALS
- Nucleus color #35d6ff (cyan), ring color #ff9a3c (orange), ribbons #b36bff (violet) fading to transparent.
- Particle size 2.2 px × DPR with a soft round sprite (discard outside r=0.5, smoothstep edge).

BEHAVIOUR
- idle: nucleus breathes, ring wobbles, no ribbons.
- listening / speaking: ribbons appear over 600ms, nucleus brightness +40%, ring speed ×2.
- waiting for approval: ring turns amber (#e8b64f) and pulses once per 1.3s.
- stopped: everything freezes except a slow fade of the ribbons; ring turns red (#ff4d57).
- Expose a tiny API: core.setState("idle"|"active"|"wait"|"stop"), core.setColors({nucleus, ring, ribbon}).
