## الخيوط اللي تتكرر في كل المراجع (مستخرجة، مب قرارات جديدة)

1. **انسخ من مكتبة، لا تبنِ من الصفر**: ThreeUI، React Bits، GetLayers، MengTo/Skills، مشاريع Jarvis الجاهزة.
2. **الخلفية مكوّن له مقابض، والثيم = مجموعة قيم** (Lightfall، Design DNA، UI UX Pro Max).
3. **الحالة تنعرض بالشكل**: قلب/كرة أو بطاقة حالة واحدة حية، وزر إيقاف دايماً ظاهر (Command Deck، JARVIS orb، thinking-orbs، ClickUp).
4. **الإيجنت عقدة لها أبناء** (نموذج، ذاكرة، أدوات)، كل خطوة تنعاد لحالها، وموافقة بشرية خطوة واضحة في المسار (كانفس n8n، Axon).
5. **المعلومات المحيطة على الأطراف، خفيفة** (Nexus، Command Deck، JARVIS HUD).
6. **الإحساس**: ظلام أزرق عميق بطبقات وضباب، مصدر ضوء دافي واحد، هدوء سينمائي، تفاصيل حية، فخامة مستقبلية دافية.
7. **الممنوعات الثابتة** (DECISIONS.md): لا كواكب ولا مدارات، لا شخصيات ولا وجوه، لا "تطبيق داكن عادي".
8. **طريقة الشغل**: صور مرجعية + قواعد تصميم مكتوبة + شاشة واحدة في كل مرة + بدون أسراب وكلاء.
