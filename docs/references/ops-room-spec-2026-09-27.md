## 0. المقدمة السينمائية (Cinematic Intro)
- عند فتح التطبيق أول مرة في كل جلسة، عرض تمهيدي قصير (٣-٥ ثواني) قبل الوصول للشاشة الرئيسية
- الكور/الشخصية "تتكوّن" من العدم — جسيمات ضوئية متناثرة تتجمع تدريجيًا لتشكّل الكور، مصحوبة بصوت تمهيدي (whoosh/power-up)
- ينتهي بانتقال سلس (fade/zoom) للشاشة الرئيسية، مع ظهور اسم "Ahmed Agent" لحظة وسط الجسيمات قبل التلاشي
- خيار "تخطي الإنترو" (Skip Intro) في الإعدادات

## 1. البنية العامة (Layout Structure)
شاشة واحدة فقط، بدون تنقّل بين شاشات:
- **الشريط العلوي (~8-10%)**: اسم الإيجنت، الحالة الحالية (Thinking/Executing/Idle/Error)، ساعة آخر نشاط، زر فتح القوائم الجانبية
- **المنطقة المركزية (~45-55%)**: الشخصية في المنتصف، فروع ضوئية مسماة (Memory, RAG, GitHub Sync, Chat Engine)
- **منطقة الحالة (Stat Strip)**: بطاقات صغيرة شفافة، حالة كل نظام فرعي (LIVE/PLANNED/ERROR)
- **منطقة الشات (~25-30%)**: طبقة نصف شفافة فوق الكور، قابلة للسحب توسيعًا/تصغيرًا
- **حقل الإدخال**: نص + مايك + إرسال، ثابت أسفل الشاشة

## 2. الألوان والخطوط (Default Theme — Black & Gold)
- خلفية أساسية: `#0A0A0B`
- سطح ثانوي: `#1A1A1C` بشفافية 80 بالمية
- اللون المميز: تدرّج ذهبي `#D4AF37` إلى `#F0C75E`
- حالة التفكير: أزرق باهت `#4A9EFF`
- حالة الخطأ: أحمر مطفي `#E5484D`
- خطوط: عنوان هندسي عصري، نص أساسي مقروء (Inter/SF Pro أو معادل)
- حواف مدورة خفيفة، ظلال ناعمة تعطي عمق

## 3. المؤثرات الصوتية (Sound Effects)
منفصلة تمامًا عن موسيقى الخلفية:
- صوت ضغط الأزرار، صوت انزلاق القوائم، صوت نجاح (success chime)، صوت خطأ مختلف، صوت انتقال حالة الكور
- مفتاح تشغيل/إيقاف مستقل في الإعدادات

## 4. حالات الشخصية/الكور (Agent State Behavior)
| الحالة | السلوك البصري |
|---|---|
| Idle | نبض بطيء هادئ، أزرق-ذهبي خافت |
| Thinking | خيوط تتحرك للداخل والخارج، أزرق أوضح |
| Executing | توهج ذهبي قوي، الفروع النشطة تنبض بسرعة |
| Success | ومضة خضراء/ذهبية سريعة، رجوع لـ Idle |
| Error | توهج أحمر على الفرع المتأثر تحديدًا، اهتزاز بصري خفيف |

## 5. تتبع التنفيذ الحي (Live Execution Path — GitHub-Connected)
- المصدر: GitHub API على ريبو `ahmed-agent` (كومتس، فروع، workflows، ملفات متغيرة)
- كل أمر يتحول لمسار من الكور للنظام الفرعي المعني، بنبض ضوئي يمثل التقدم لحظة بلحظة
- الارتداد (backtrack) يُعرض بحركة معاكسة على نفس المسار
- تحديث: polling كل 5-10 ثواني، أو websocket لاحقًا

## 6. أنماط عرض الـ Workflow البديلة
- **Core View** (افتراضي)، **Tree View**، **Hierarchy View**، **Grid View**
- نفس البيانات الحية بأشكال هندسية مختلفة

## 7. التحكم اليدوي بالهيكل
- زر "+" لإضافة عقدة/مسار يدوي
- ضغط مطوّل لحذف/تعديل عقدة
- التعديلات تُخزّن وتُزامن مع ملف تهيئة (`agent-structure.json`)

## 8. القوائم الجانبية (Side Panels)
- تنزلق من الطرف (~250-300ms ease-out)، خلفية الشاشة تبقى خافتة خلفها
- قابلة للتحجيم: تصغير لربع الشاشة أو إغلاق كامل
- **تبويب الأخطاء والتفاصيل**: قائمة زمنية بآخر الأحداث
- **تبويب الإضافات/الموصلات**: كروت لكل نموذج (ChatGPT, Claude, Gemini, Kimi) بحالة اتصال وزر تفعيل/تعطيل

## 9. الإعدادات (Settings Screen)
- الثيم: منتقي ألوان وخطوط كامل، معاينة حية
- ثيمات جاهزة (presets) بمعاينة مصغرة
- استيراد ثيم خارجي (JSON)
- موسيقى/صوت الخلفية: تشغيل/إيقاف + مستوى الصوت + النوع
- المؤثرات الصوتية: تشغيل/إيقاف منفصل
- شخصية الإيجنت: الكور الحي / الرفيق الآلي / الحارس
- تخطي الإنترو: تشغيل/إيقاف
- **تقليل الحركة (Reduce Motion)**: يقلل كثافة الجسيمات والحركة للي يحتاج تجربة أهدأ بصريًا
- اللغة، ترتيب العناصر (drag-to-rearrange)

## 10. الصوت التفاعلي (Voice Interaction)
- زر مايك بمؤشر موجة صوتية حية
- رد صوتي (نص إلى كلام) مصحوب بحركة بصرية على الشخصية
- دعم أساسي بالإنجليزي أولاً

## 11. الشات (Chat)
حاضر ومباشر في الشاشة الرئيسية، الشخصية تتفاعل بصريًا أثناء الحوار.

## 12. الأداء المنخفض وانقطاع الاتصال
- **أداء منخفض**: الكور يتحول لنسخة أبسط (جسيمات أقل) دون التحول لتصميم مسطح كامل
- **انقطاع GitHub تحديدًا**: التطبيق يستمر شغال طبيعي على آخر بيانات متصلة (last synced state)، مع مؤشر صغير واضح (مثلاً بجانب اسم الفرع/الريبو) يبين إن مزامنة GitHub غير متصلة، لحين رجوع الاتصال
